
# FIXCUT - 월 고정비 다이어트 플랫폼

## 1분 배포
1. 이 코드를 GitHub에 업로드
2. Vercel.com -> New Project -> GitHub 연결 -> Deploy
3. Vercel Environment Variables에 Supabase URL/KEY 입력

## Supabase 설정
- supabase.com -> New Project
- SQL Editor에서 supabase_schema.sql 붙여넣기 (프로젝트 루트에 있음)

## 수익 구조
- 통신 CPA: 2~4만원 / 대출 중개: 평균 140만원 / 프리미엄: 월 3900원
